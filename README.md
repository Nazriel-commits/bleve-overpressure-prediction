# BLEVE Explosion Overpressure Prediction

## Overview
Boiling Liquid Expanding Vapor Explosions (BLEVEs) pose serious safety risks during LPG transport.  
This project applies machine learning to predict **peak overpressure** generated by BLEVE blast waves using sensor data from a 3D environment with obstacles.  
The goal was to achieve a low Mean Absolute Percentage Error (MAPE) on unseen test data.

## Dataset
- **Samples:** 10,050 training, 3,203 test  
- **Features:** 24 variables (tank geometry, temperatures, pressures, sensor coordinates, obstacle dimensions)  
- **Target:** Peak pressure (0.016–9.17 bar)  
- **Source:** Simulated BLEVE sensor dataset (Kaggle competition)

## Data Preprocessing
- **Missing values:** Median imputation (<0.5% missing)  
- **Categorical encoding:** Binary encoding for `Status` (Subcooled = 0, Superheated = 1)  
- **Scaling:** StandardScaler for linear/SVR models only  
- **Dropped:** 10 rows with missing target values  

## Feature Engineering
Six domain‑informed features were created:
| Feature | Formula | Description |
|----------|----------|-------------|
| Tank Aspect Ratio | Width / Length | Tank shape characteristic |
| Tank Volume | Width × Length × Height | Total tank capacity |
| Distance to Sensor | √(x² + y² + z²) | Spatial relationship |
| Vapor Temp‑Pressure | Vapor Temp × Failure Pressure | Thermal‑mechanical effect |
| Liquid Temp‑Pressure | Liquid Temp × Failure Pressure | Thermal‑mechanical effect |
| Gas Ratio | Vapor Height / Tank Height | Gas‑to‑liquid ratio |

These features improved MAPE by ~12.5% and appeared in the top 10 feature importance rankings.

## Models Evaluated
| Family | Algorithm | Notes |
|---------|------------|-------|
| Linear | Ridge Regression | Baseline |
| Kernel | SVR (RBF) | Non‑linear relationships |
| Tree‑based | Random Forest, XGBoost, LightGBM | Captures complex interactions |

## Hyperparameter Tuning
Used **GridSearchCV (5‑fold CV)** with negative MAPE scoring.

| Model | Best CV MAPE | Notes |
|--------|---------------|-------|
| Random Forest | 0.373 | Baseline ensemble |
| XGBoost | 0.312 | Tuned |
| LightGBM | 0.247 | Optimized final model |

**Final configuration (LightGBM):**
- `n_estimators = 800`
- `max_depth = 10`
- `learning_rate = 0.02`
- `subsample = 0.7`
- `colsample_bytree = 0.7`

## Results
| Model | CV MAPE | Kaggle MAPE | Improvement |
|--------|----------|-------------|--------------|
| Random Forest | 0.373 | 0.404 | Baseline |
| XGBoost | 0.312 | 0.306 | +24% |
| LightGBM | 0.247 | 0.238 | +41% |

**Final score:** 0.23799 (Kaggle public leaderboard)

## Key Insights
- Cross‑validation gives more reliable estimates than single validation splits.  
- Feature engineering contributed more to improvement than algorithm choice.  
- LightGBM’s leaf‑wise growth and histogram binning handled tabular data best.  
- Overfitting was diagnosed and mitigated using 5‑fold CV.

## How To Run

1. Open `main.ipynb` in Jupyter Notebook or Google Colab.
2. Place the Kaggle `train.csv` and `test.csv` files in the same directory as the notebook.
3. Install required packages:
   -pip install pandas numpy scikit-learn xgboost lightgbm matplotlib
4. Run all cells in order

*Note: Dataset is from the BLEVE Peak Pressure Kaggle competition and is not included in this repository.*
